1. Write a DAX measure to calculate Total Sales.

Say:

“I'll create a measure using SUM() on the Sales Amount column.”

Total Sales =
SUM(Sales[SalesAmount])

2. Difference between a Measure and a Calculated Column. Show how to create each.

Say:

“A calculated column is calculated row by row and stored in the model. A measure is calculated dynamically based on filter context.”

Calculated Column:

Total Amount =
Sales[Quantity] * Sales[UnitPrice]

Measure:

Total Sales =
SUM(Sales[SalesAmount])

3. Difference between SUM() and SUMX(). Write an example of both.

Say:

“SUM() adds values from one column. SUMX() iterates through a table row by row and evaluates an expression.”

Total Sales =
SUM(Sales[SalesAmount])

Total Sales =
SUMX(
    Sales,
    Sales[Quantity] * Sales[UnitPrice]
)

4. Explain Row Context vs Filter Context with a practical example.

Say:

“Row context means DAX is evaluating one row at a time, mainly in calculated columns and iterators. Filter context is the filters coming from visuals, slicers, relationships, or DAX.”

Row Context:

Total Amount =
Sales[Quantity] * Sales[UnitPrice]

Filter Context:

Total Sales =
CALCULATE(
    SUM(Sales[SalesAmount]),
    Product[Category] = "Electronics"
)

5. What is CALCULATE()? Calculate sales for a specific category.

Say:

“CALCULATE() evaluates an expression after modifying the filter context.”

Electronics Sales =
CALCULATE(
    [Total Sales],
    Product[Category] = "Electronics"
)

6. What is Context Transition? Show an example using CALCULATE().

Say:

“Context transition converts the current row context into filter context. CALCULATE() performs this transition.”

Customer Sales =
CALCULATE(
    [Total Sales]
)

“For example, when CALCULATE() is used inside an iterator or calculated column, the current row can become a filter.”

7. Use FILTER() inside CALCULATE() to calculate sales based on a condition.

Say:

“I'll use FILTER() when I need a table expression with a condition.”

High Value Sales =
CALCULATE(
    [Total Sales],
    FILTER(
        Sales,
        Sales[SalesAmount] > 1000
    )
)

8. Create a measure using VAR.

Say:

“Variables make DAX easier to read, avoid repeating calculations and can improve performance.”

Profit Margin =
VAR TotalSales = [Total Sales]
VAR TotalCost = [Total Cost]
VAR Profit = TotalSales - TotalCost
RETURN
DIVIDE(Profit, TotalSales)

9. Calculate YTD Sales.

Say:

“I'll use TOTALYTD() with my Date column.”

YTD Sales =
TOTALYTD(
    [Total Sales],
    'Date'[Date]
)

10. Calculate MTD Sales.

MTD Sales =
TOTALMTD(
    [Total Sales],
    'Date'[Date]
)

Say:

“TOTALMTD() calculates sales from the beginning of the current month to the current date.”

11. Calculate QTD Sales.

QTD Sales =
TOTALQTD(
    [Total Sales],
    'Date'[Date]
)

12. Calculate Previous Year Sales using SAMEPERIODLASTYEAR().

Say:

“I'll shift the current date context back by one year.”

Previous Year Sales =
CALCULATE(
    [Total Sales],
    SAMEPERIODLASTYEAR('Date'[Date])
)

13. Calculate YoY Sales Growth %.

Say:

“I'll compare current sales with previous-year sales.”

YoY Growth % =
VAR CurrentSales = [Total Sales]
VAR PreviousSales = [Previous Year Sales]
RETURN
DIVIDE(
    CurrentSales - PreviousSales,
    PreviousSales
)

14. Calculate Month-over-Month Sales Growth %.

Say:

“I'll calculate previous-month sales and compare it with current sales.”

Previous Month Sales =
CALCULATE(
    [Total Sales],
    DATEADD('Date'[Date], -1, MONTH)
)

MoM Growth % =
DIVIDE(
    [Total Sales] - [Previous Month Sales],
    [Previous Month Sales]
)

15. Create a running/cumulative Sales measure.

Say:

“I'll use CALCULATE() with FILTER() to include all dates up to the current date.”

Cumulative Sales =
CALCULATE(
    [Total Sales],
    FILTER(
        ALL('Date'[Date]),
        'Date'[Date] <= MAX('Date'[Date])
    )
)

16. Create a rolling 30-day Sales measure.

Say:

“I'll create a date window covering the current date and previous 29 days.”

Rolling 30 Days Sales =
CALCULATE(
    [Total Sales],
    DATESINPERIOD(
        'Date'[Date],
        MAX('Date'[Date]),
        -30,
        DAY
    )
)

17. Create a Top 5 Products by Sales using TOPN().

Say:

Top 5 Products =
TOPN(
    5,
    ALL(Product[ProductName]),
    [Total Sales],
    DESC
)
